## Overview

This week covered reconnaissance (footprinting) — the first phase of the
penetration testing lifecycle — using a mix of command-line tools, Google
dorking, OSINT frameworks, and GUI-based intelligence/network-scanning tools.
The goal was to understand how much information about a target (a domain,
an organization, or a network) can be gathered before any active exploitation
is attempted.

## Key Skills Demonstrated
- Domain and DNS reconnaissance (whois, nslookup, dnsrecon)
- Web technology and WAF fingerprinting (whatweb, wafw00f, curl)
- Google dorking for exposed/misconfigured resources (GHDB)
- Graph-based OSINT and link analysis (Maltego)
- Email and subdomain harvesting from public sources (theHarvester)
- Local network discovery and host enumeration (Zenmap/Nmap)
